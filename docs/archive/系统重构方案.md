## 二、重构目标

### 2.1 核心目标

1. **修复阻断性缺陷**（P1-P4）：MinIO 初始化、worker 链路、CORS 配置、Docker 构建
2. **提升工程整洁度**（P5-P8, P11-P14）：清理临时文件、分组后端服务、补充工具函数
3. **优化前端性能**（P9）：antd chunk 按需引入、懒加载优化
4. **解耦编辑器组件**（P10）：WordEditorPage 拆分为多个 composable + 子组件
5. **贯通 P3/P4 能力**（P15）：将已写但未集成的 composable 接入主链路

### 2.2 不做什么

- **不更换技术栈**：Vue3+TS / FastAPI / LangGraph / pgvector / MinIO / Redis+Arq 全部保留
- **不重写已有组件**：WordEditor 系列已验证可用（P0 验收通过 + 构建通过），仅在原有基础上拆分/增强
- **不改动 LangGraph 工作流逻辑**：12 节点状态图、HITL 中断、checkpoint 机制全部保留
- **不改动 DB schema**：18 个 Alembic 迁移保持不变
