# 架构决策记录（ADR）

本目录以轻量 ADR（Architecture Decision Record）形式沉淀关键架构决策，供后续开发、评审与新人理解「为什么这么做」。

## 规则

1. **何时写**：任何影响架构方向、跨模块边界、或后续难以逆转的决策（分层、数据模型、技术选型、安全模型），提交代码前先落 ADR。
2. **命名**：`NNNN-标题-kebab-case.md`，编号递增不重复。
3. **状态**：`提议` → `已接受` / `已否决` / `已废弃`（被新 ADR 取代时在旧 ADR 标注 Superseded by）。
4. **模板**：复制 [0000-template.md](./0000-template.md)。
5. **引用**：在 SDD.md 相关章节标注 `参见 ADR-NNNN`，避免重复描述。
