## 一、MVP 总览

**MVP 目标**：输入招标文件（PDF/Word）+ 公司资料库，输出符合招标评分标准的**可编辑 Word 技术方案初稿**与评分点对标报告。

**核心闭环（P0，已完成）**：

```
招标解析 → 评分对标 → 骨架生成 → 章节生成 → Word 导出
```

| 阶段 | 关键能力 | 状态 |
|---|---|---|
| 1. 招标解析 | PDF/Word → 评分点/★条款/资格要求结构化提取 | ✅ 已落地 |
| 2. 评分对标 | 逐条需求 → 应答策略 → 得分预估 | ✅ 已落地 |
| 3. 骨架生成 | 章节大纲 + 目录结构 | ✅ 已落地 |
| 4. 章节生成 | RAG 增强逐节撰写 + 流式输出 | ✅ 已落地 |
| 5. Word 导出 | 固定模板（封面/目录/正文/附表） | ✅ 已落地 |

## 二、P0 — 核心闭环（当前版本）

- 账号登录 + 项目级隔离（RBAC 功能权限 × 项目成员表数据范围，双维正交）
- 招标文件解析（PDF/Word → 结构化评分点、废标/★条款、资格要求）
- 评分点对标分析
- 方案骨架生成与章节内容生成（含格式/资质校验）
- 章节级人工审阅反馈与局部重写
- 流式输出
- Word 文档导出（固定模板）
- 项目成员管理（owner/协作者，两级）

## 三、P1 — 体验必需（已提前落地）

> 注：以下项在 MVP 迭代中提前完成，已属当前系统能力。

- 真实资料批量入库与向量检索（RAG 底座：pgvector + bge-m3 embedding）
- 云端 rerank 精排 + 离线评测框架（eval 数据集/指标/门禁）
- 完整 RBAC（角色/权限/审计日志）
- 废标条款识别与贯穿校验（disqualification 红线检测）
- 章节分工与多成员协作流（division）
- 知识库管理（KB 多库 + 全局检索）
- LLM 多提供商配置（自定义端点 + DeepSeek/DashScope 等）

## 四、P2 — 后续迭代（规划中，未排期）

- 编辑器增强：行内批注 / diff 对比、版本历史可视化
- 大纲与章节的 AI 辅助改写（选区/整章 assist 已具备，扩展更多模式）
- 生成质量 benchmark 榜单化（现有 eval 框架上扩展）

## 五、范围外（二期，不纳入 MVP）

- 版本管理与 diff（重写即覆盖 + updated_at 留痕）
- 多模型路由降级（当前为固定主/备模型）
- OCR 扫描件解析（当前要求文本型 PDF/Word）
- 商务标 / 报价标生成
- 私有化离线部署（当前 Docker Compose 单机部署）

## 六、架构与运维基线（MVP 锁定）

| 项 | 基线 | 迁移路径 |
|---|---|---|
| 向量库 | pgvector（单库） | → Milvus |
| 消息/任务 | Redis + Arq | 保持不变 |
| 编排 | LangGraph + PostgresSaver | 保持不变 |
| 部署 | Docker Compose 单机 | → K8s |
| 前端 | Vue3 + TS + Vite（pnpm） | 保持不变 |
| 测试 | pytest（覆盖率≥70%，关键模块≥80%）+ vitest + Playwright E2E | 保持不变 |
